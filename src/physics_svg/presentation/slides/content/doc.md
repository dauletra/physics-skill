# `content` — объяснение

Рабочая лошадка урока: заголовок, абзац, список, иллюстрация — в любом
непустом сочетании. Как расположить их на экране, решает плеер.

```template
basic
```

| поле | обяз. | значения |
|---|---|---|
| `heading` | нет | заголовок слайда |
| `text` | нет | абзац объяснения |
| `items` | нет | список, по строке на пункт |
| `visual` | нет | спека иллюстрации — та же, что в документе |

Хотя бы одно из `text`, `items`, `visual` обязательно: заголовок сам по
себе анонсирует объяснение, которого нет. Длинное объяснение — это
несколько слайдов `content`, а не один переполненный: слайд читают с
последней парты.

**Сколько помещается.** Замерено на кадре при том кегле, с которым слайд
читается с задней парты: **10 строк** сплошного текста **или 8 пунктов**
списка. Если на слайде есть иллюстрация, на текст остаётся **4 строки** —
дальше плеер сам разложит слайд в две колонки, а если и это не поможет,
опустит кегль на ступень. Считать это запасом не надо: ступень вниз —
аварийный клапан, а не место, куда можно дописать ещё абзац.

Объяснение, которое опирается на картинку:

```template
with-visual
```

Куда встанет иллюстрация, спека не задаёт: широкий график идёт над текстом
во всю ширину кадра, высокий прибор или векторная диаграмма — рядом с ним.
Показ меряет подпись картинки и выбирает сам.

```template
with-instrument
```

Слайд, у которого текста нет вовсе: разбирают саму картинку, а говорит
учитель. Иллюстрация берёт весь кадр — только так график читается с задней
парты.

```template
figure
```

Перечисление — списком, а не абзацем с запятыми: с последней парты список
читается, а длинная фраза нет.

```template
checklist
```

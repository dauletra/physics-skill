# `graph` — график с осями

Задаются **данные**, не рисунок: диапазоны осей и точки серий. Деления,
сетку, раскладку и легенду выбирает рендерер.

```json
{
  "type": "graph",
  "x_label": "t, с",
  "y_label": "υ, м/с",
  "x_range": [0, 8],
  "y_range": [0, 20],
  "series": [
    { "points": [[0, 4], [8, 20]], "label": "тело 1" },
    { "points": [[0, 0], [8, 12]], "label": "тело 2", "style": "dashed" }
  ]
}
```

| поле | обяз. | значения |
|---|---|---|
| `x_label`, `y_label` | да | подпись с единицей: `«t, с»`, `«υ, м/с»` |
| `x_range`, `y_range` | да | `[min, max]`, `min < max` |
| `chart_type` | нет | `line` (по умолчанию), `bar`, `scatter` |
| `grid` | нет | `ticks` (по умолчанию), `fine` |
| `series` | нет | список серий; пустой — только оси и сетка |

Серия: `points` (список `[x, y]`, хотя бы одна точка), `label` (подпись в
легенде), `style` (`solid`/`dashed`/`dotted`).

## Правила

- **Диапазон задаёшь ты, деления — рендерер.** Шаг делений всегда круглый
  (1/2/5 × 10ⁿ), поэтому бери круглые границы: `[0, 8]`, а не `[0, 7.3]`.
- `grid: "fine"` дробит деление на 5 — ставь, когда по графику **снимают**
  значения между подписями или строят точки. Полноразмерная миллиметровка —
  это `paper`, а не график.
- `chart_type: "bar"` — только одна серия и `y_range` строго от нуля:
  столбик, растущий не от нуля, врёт о соотношении высот.
- Точки серии соединяются в порядке списка — сортируй по x сам.
- Пустой `series` — нормальный график: оси с сеткой под построение от руки.
- Легенда рисуется сама, если у серий есть `label`; для одной серии подпись
  обычно не нужна.

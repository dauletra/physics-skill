# `paper` — место для работы ученика

Разлинованное поле. Чистый компонент: сам по себе он ничего не спрашивает,
что на нём делают — говорит соседний вопрос.

```json
{ "type": "paper", "ruling": "lines", "rows": 4 }
```

| поле | обяз. | значения |
|---|---|---|
| `ruling` | нет | `lines` (по умолчанию), `plain`, `grid`, `dots`, `mm` |
| `rows` | да | высота в строках/клетках разлиновки |
| `cols` | для клетчатых | ширина в клетках |

**Единица `rows`/`cols` — клетка самой разлиновки, не пиксель и не
миллиметр.** У `mm` клетка сантиметровая: `"rows": 12, "cols": 12` — это
поле 12×12 см, а не 12×12 мм.

## Что когда ставить

- **расчёт, вывод формулы, развёрнутый ответ** → `lines`, 2–3 строки на
  короткую подстановку, 4–6 на вывод;
- **«постройте график»**, если оси не заданы → `mm`, `"rows": 12,
  "cols": 12`; если оси с диапазонами задаёшь ты — это вопрос `plot`, там
  оси уже нарисованы;
- **чертёж, схема опыта** → `plain` или `dots`, 6 строк;
- **отвечают устно или пишут в соседней таблице** → блока нет вообще.

## Ограничения

- `grid`, `dots`, `mm` требуют `cols`: квадратную клетку нельзя растянуть по
  ширине колонки. `lines` и `plain` без `cols` занимают всю колонку.
- Ширина: не больше ширины колонки — 40 клеток `grid`/`dots`, 16 клеток `mm`.
- Высота: не больше ~2 экранов — 50 строк `lines`, 30 клеток `mm`.

# Пропуски в тексте

Предложение или абзац с пробелами, которые нужно заполнить.

Годится для определений, формулировок законов и единиц. Можно дать список
слов на выбор — тогда задание проще, без списка нужно вспоминать самому.

**Что сказать Claude**

- «вставить пропущенные слова в определение равномерного движения»
- «текст с пропусками, слова для выбора дай списком»
- «пусть впишут единицы измерения в формулировку второго закона Ньютона»

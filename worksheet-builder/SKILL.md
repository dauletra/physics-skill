# Worksheet Builder

Собирает рабочий лист в два слоя: **контент — маленькие JSON-файлы** (по
одному на задание), **вёрстка — детерминированный рендерер**, который
превращает их в самодостаточный HTML (центрированная колонка ~800px,
открывается в любом браузере). Единый стиль всех листов гарантирует код
рендерера, а не память между сообщениями.

## Запуск рендерера

Ставить ничего не нужно, все команды — так:

```
python <путь-к-skill>/scripts/render.py <папка-черновика>
```

При первом запуске в сессии `render.py` сам доустановит pydantic (несколько
секунд, нужна сеть); дальше рендеры мгновенные. Если установка не удалась —
он напечатает понятную ошибку, сообщи её учителю.

## Жёсткие правила

1. **Никогда не пиши итоговый HTML рабочего листа руками** — твоя работа
   только контент в JSON по схеме `references/task-schema.md`; вёрстку
   делает рендерер. В сгенерированном HTML ничего не редактируется — любая
   правка идёт через JSON и пересборку.
2. **Перед созданием или правкой JSON читай `references/task-schema.md`** —
   там вся схема: `meta.json`, дерево блоков, все виды вопросов и контейнеры.
   Схема строго проверяется при сборке: опечатка в поле, неизвестное
   значение, битая ссылка — ошибка с точным путём до блока, все ошибки
   перечисляются разом.
3. **Файлы сессии эфемерны.** Итог отдавай учителю на скачивание; чтобы
   вернуться к листу в другой сессии, черновик надо будет загрузить обратно.
4. **Правка = редактирование одного `task-NN.json`.** Не перечитывай и не
   переписывай остальные файлы или собранный HTML ради одной правки.

## Фаза 1 — обсуждение и черновик

1. Проясни тему, класс/возраст, набор и количество заданий. Можно начинать
   с одного-двух заданий и добавлять по ходу разговора.
2. Заведи папку черновика (слаг по теме, например `kinematics-9th-grade/`)
   с `meta.json` и по файлу `tasks/task-NN.json` на задание: `id` совпадает
   с именем файла, `order` в `meta.json` перечисляет все файлы. Если учитель
   продолжает ранее начатый лист — сначала попроси загрузить черновик.
3. Задание — дерево блоков: чистые компоненты (`text`/`table`/`graph`/
   `list`), один из 9 видов вопросов (`open`, `choice`, `match`, `fill_text`,
   `fill_table`, `plot`, `true_false`, `rank`, `classify` — ответ инлайн),
   контейнер-подзадание `part` для пунктов а)/б)/в) и layout-контейнер `row`
   для блоков бок о бок. Состав и инварианты — в `references/task-schema.md`.
   Готовую задачу учителя просто оформи подходящим видом вопроса; «придумай
   задачи по теме» — сочиняй сам под класс/уровень.
4. Обозначения и формулы: обычный текст и Unicode-символы (`α`, `≠`, `м/с²`,
   `υ₀`), LaTeX — только для действительно сложного (дроби, корни). Скорость
   — греческая `υ`, не латинская `v`. Перед формулами сверься с
   `references/symbols.md`.
5. Графики (`graph`/`plot`) — не рисуй SVG сам, задай данные
   (`x_range`/`y_range`/`series`) по `references/charts-and-graphs.md`.
   Иллюстрации/схемы (наклонная плоскость, электрическая цепь) не
   поддерживаются — опиши условие текстом.
6. Быстрый просмотр одного задания без сборки всего листа:
   ```
   python <путь-к-skill>/scripts/render.py <папка> --task task-03
   ```
   даёт `task-03.preview.html` в реальных стилях (по умолчанию с ответами;
   `--mode student` — версия ученика).

## Фаза 2 — сборка и выдача

Когда учитель говорит «собери лист» — запусти команду запуска на папке
черновика. Появятся `<папка>/output/worksheet-student.html` (без ответов) и
`worksheet-teacher.html` (с ответами). Ошибки схемы печатаются все разом с
путями до блоков — исправь указанные JSON и собери снова.

Отдай на скачивание **оба HTML и папку-черновик JSON** — черновик нужен,
чтобы вернуться к правкам в другой сессии. Правки после просмотра: измени
нужный `task-NN.json` (или `meta.json`) и пересобери — это мгновенно и
бесплатно, повторяй сколько угодно.

## Справочники — когда какой читать

- `references/task-schema.md` — **перед любым созданием/правкой JSON.**
- `references/symbols.md` — перед записью формул и обозначений.
- `references/charts-and-graphs.md` — перед созданием графика.
- `references/artifacts/` — нюансы конкретного типа графика
  (`README.md` — индекс, `graphs.md` — разбор по типам).
- `references/design-system.md` — только для вопросов о внешнем виде; стиль
  зафиксирован кодом рендерера и в сессии не меняется.
- `examples/kinematics-9th-grade/` — проработанный образец: все 9 видов
  вопросов, задание с двумя `part` вокруг общего графика (task-10), `row`
  из двух `part` с `plot` (task-13), иерархия символов (task-09).

# Верно или неверно

Серия утверждений, каждое нужно оценить. У каждого — два квадратика,
«Верно» и «Неверно».

Быстрый способ разобрать формулировки и поймать типичные заблуждения.

**Что сказать Claude**

- «шесть утверждений про векторные и скалярные величины»
- «половина утверждений пусть будет с распространёнными ошибками»

# `prompt` — вопросы классу

Экран с вопросами, которые учитель задаёт вслух: актуализация в начале
урока, проверка понимания после объяснения. Ответов в данных нет — их дают
голосом, а не показывают.

```json
{
  "type": "prompt",
  "items": [
    "Что показывает наклон графика скорости?",
    "Как движется тело, если график υ(t) — горизонтальная прямая?",
    "Может ли скорость расти, а ускорение уменьшаться?"
  ]
}
```

| поле | обяз. | значения |
|---|---|---|
| `items` | да | вопросы, минимум один; по строке на вопрос |

Ответ на вопрос класса в схеме не предусмотрен: `prompt` — это то, что
учитель спрашивает, а не то, что он показывает. Нужен разбор с решением —
это [`example`](example.md), нужен ответ для учителя — задача у доски
([`board_task`](board_task.md)).

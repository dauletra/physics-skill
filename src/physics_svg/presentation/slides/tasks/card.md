# Набор задач

Две-четыре задачи на одном экране: класс работает по рядам или в парах, а
не смотрит на доску. У каждой задачи свой ответ, ряд ответов стоит по низу
слайда.

В плеере учитель открывает ответ той задачи, до которой дошёл класс; в
файле PowerPoint ответы открываются по очереди, с первой задачи — там один
поток щелчков и выбрать из него нельзя. Если класс решает вразнобой, ответы
на экран лучше не выводить. Картинки помещаются только при двух задачах:
три и четыре — это уже два слайда.

**Что сказать Claude**

- «слайд с тремя задачами для работы в парах»
- «дай четыре задачи на экран, ответы спрячь»
- «две задачи с графиками рядом»

# `vectors` — векторная диаграмма

Силы на теле, сложение векторов, разложение на составляющие.

```json
{
  "type": "vectors",
  "arrangement": "common",
  "body": "block",
  "grid": true,
  "vectors": [
    { "length": 4, "angle": 0, "label": "F" },
    { "length": 3, "angle": 180, "label": "F<sub>тр</sub>" }
  ],
  "resultant": "R",
  "caption": "1 клетка = 10 Н"
}
```

| поле | обяз. | значения |
|---|---|---|
| `vectors` | да | от 1 до 6 векторов |
| `arrangement` | нет | `common` (по умолчанию) — все из одной точки; `chain` — цепочкой, конец к началу; `parallelogram` — ровно два вектора и достроенный параллелограмм |
| `body` | нет | `point`, `block`, `ball` — тело в точке приложения; только при `common` |
| `resultant` | нет | подпись равнодействующей; сама она **вычисляется**, задавать её длину и угол не нужно |
| `grid` | нет | клетчатый фон, чтобы длины можно было сосчитать |
| `angles` | нет | дуги углов между векторами |
| `caption` | нет | подпись под рисунком |

Вектор: `length` (длина в клетках, 0 < length ≤ 12), `angle` (градусы),
`label` (подпись у наконечника), `style` (`solid`/`dashed`), `id` (нужен,
только если на вектор ссылается угол).

## Длина — в клетках, угол — от горизонтали

**`length` не в ньютонах и не в пикселях, а в клетках.** Учебник рисует
30 Н тремя клетками и подписывает «1 клетка = 10 Н» — делай так же: числа
3 и 4 всегда нарисуются в отношении 3:4, какого бы размера ни вышел рисунок.
Масштаб клетки подбирает рендерер.

**`angle` — как измеряют транспортиром**: 0 — вправо, 90 — вверх, 180 —
влево, −90 (или 270) — вниз.

## Правила

- **Равнодействующая вычисляется сама** по заданным векторам; `resultant` —
  только её подпись. Пунктирные векторы (`style: "dashed"`) в сумму не
  входят: они построения, а не силы.
- При `common` равнодействующая рисуется рядом со сдвигом — иначе на
  диаграмме коллинеарных сил она легла бы прямо на одну из них.
- Почти нулевая равнодействующая — ошибка: рисовать нечего. Если задача про
  равновесие, скажи это условием, а не стрелкой нулевой длины.
- **Угол к горизонтали** отмечается так: добавь пунктирный вектор с
  `angle: 0`, дай ему `id` и поставь дугу между ним и нужной силой. Отдельного
  «горизонта» в схеме нет — на диаграмме он и так рисуется линией.
- `angles` ссылаются на `id` векторов, а не на их позиции.

## Чего тут нет

Опоры, наклонной плоскости, нити и блока — это не векторная диаграмма, а
схема механизма; такого типа пока нет. Тело (`body`) — единственный
предмет, который умеет эта диаграмма.

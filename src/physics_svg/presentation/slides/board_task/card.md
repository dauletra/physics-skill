# Задача у доски

Условие задачи на весь экран — для решения у доски, пока класс следит.
Ответ — для учителя, отдельной строкой внизу слайда. Серия задач —
несколько слайдов, по задаче на каждый.

В HTML-плеере ответ спрятан под плашкой и открывается щелчком по ней;
в файле PowerPoint он пока виден сразу — если показывать его классу рано,
проще собрать слайд без `answer`.

**Что сказать Claude**

- «добавь две задачи для решения у доски»
- «задачу с графиком — на слайд, с ответом для меня»
- «после объяснения — задача на закрепление у доски»

# `true_false` — верно или неверно

Разобрать серию утверждений: проверка формулировок и типовых заблуждений.

```json
{
  "type": "task",
  "blocks": [
    { "type": "text", "body": "Отметьте, верны ли утверждения." },
    {
      "type": "true_false",
      "statements": [
        { "text": "Скорость — векторная величина", "answer": true },
        { "text": "Путь может быть отрицательным", "answer": false }
      ]
    }
  ]
}
```

| поле | обяз. | смысл |
|---|---|---|
| `statements` | да | утверждения; `answer` — правильный вердикт инлайн |

Утверждения печатаются под буквами `а)`, `б)`, `в)` — это метки внутри
вопроса, а не подзадания: в `part` их заворачивать не надо. У каждого — два
квадратика «Верно»/«Неверно». В ответе — строка вида `а — Верно, б — Неверно`
по тем же буквам. Больше 28 утверждений не бывает: кончается алфавит.

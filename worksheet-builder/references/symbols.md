# Символы: когда текст, когда LaTeX

Правило приоритета для любого не-ASCII знака в `prompt`/`answer`/тексте задания —
всегда бери самый простой вариант, который справляется:

1. **Обычный текст (Unicode-символ)** — таблицы ниже. Работает везде, не
   зависит от KaTeX/интернета, ничем не отличается по шрифту от остального
   текста, безопасно использовать даже внутри `text_template`/`left_items`/
   `right_items`/любых других полей.
2. **`<sup>...</sup>` / `<sub>...</sub>`** — только если нужен верхний/нижний
   индекс, для которого нет отдельного Unicode-символа (произвольная буква,
   многосимвольный индекс). Эти два тега — единственный HTML, который
   рендерер пропускает как есть; весь остальной текст экранируется, так что
   никакой другой разметки в JSON писать не нужно и не получится.
3. **LaTeX `$...$` / `$$...$$`** — только когда это реально составное
   математическое выражение, которое не читается как обычный текст: дробь,
   корень с содержимым под ним, система уравнений, интеграл, сумма с
   пределами. Одна греческая буква, знак сравнения или единица измерения —
   **не** повод открывать `$...$`.

Почему так: LaTeX тянет за собой KaTeX (CDN, нужен интернет) и на письме
выглядит другим шрифтом/кеглем, чем остальной текст — оправдано только когда
даёт реальную читаемость, которую иначе не получить. К тому же пропуск
(`___N___`) внутри `$...$` ломает рендер формулы (см. `task-schema.md`) — ещё
одна причина не заворачивать в LaTeX то, что не обязано там быть.

## Операторы и сравнение

| Символ | Значение |
|---|---|
| ≠ | не равно |
| ≡ | тождественно равно |
| ≈ | приблизительно равно |
| ± | плюс-минус |
| ° | градус |
| § | параграф |
| ∙ | умножение (точка) |
| × | умножение (крест) — для записи вида `3 × 10⁻⁵` |
| ÷ | деление |
| √ | корень (для простых случаев без сложного содержимого) |
| ≥ | больше или равно |
| ≤ | меньше или равно |
| ∞ | бесконечность |
| ∝ | пропорционально |
| → | стрелка (направление, переход) |
| ⊥ | перпендикулярно |
| ∥ | параллельно |
| ′ | штрих (угловые минуты, производная по времени: `s′`) |
| ″ | два штриха (угловые секунды) |

## Надстрочные и подстрочные цифры

Покрывают частые случаи (`м²`, `с⁻¹`, `υ₀`, `x₁`) без `<sup>`/`<sub>`:

| Обычная | Надстрочная | Подстрочная |
|---|---|---|
| 0 | ⁰ | ₀ |
| 1 | ¹ | ₁ |
| 2 | ² | ₂ |
| 3 | ³ | ₃ |
| 4 | ⁴ | ₄ |
| 5 | ⁵ | ₅ |
| 6 | ⁶ | ₆ |
| 7 | ⁷ | ₇ |
| 8 | ⁸ | ₈ |
| 9 | ⁹ | ₉ |
| - (минус) | ⁻ | ₋ |
| + | ⁺ | ₊ |

Если нужен индекс с буквой или несколькими символами (например, `x_max`,
`t₍общ₎`) — этого набора не хватит, используй `<sup>`/`<sub>`:
`x<sub>max</sub>`, `t<sup>общ</sup>`.

для физических обозначений не нужна, используй `σ`). `ϕ` — альтернативное
начертание фи, обе формы равнозначны, для единообразия в рабочих листах
используй `φ`.

## Внимание: буквы, неотличимые от латиницы на печати

В шрифтах дизайн-системы (`"PT Sans", "Segoe UI", Verdana, Arial`) часть
греческих букв визуально **совпадает** с латинскими — это не баг рендера, а
свойство самих начертаний (то же самое было бы в любом учебнике физики). Мы
проверили это на практике, отрендерив пары рядом:

- `ν` (ню) на печати выглядит **ровно как латинская `v`** — не отличить
  вообще. Поэтому в этом проекте скорость обозначается греческой `υ`
  (ипсилон), а не латинской `v`: так частота (`ν`) и скорость (`υ`) остаются
  двумя разными, узнаваемыми символами. Если бы вместо `υ` использовалась
  `v`, она была бы неотличима от `ν` на бумаге.
- `ν` (ню, частота) и `υ` (ипсилон, скорость) друг от друга при этом
  **отличаются нормально** — у ню чёткий острый низ (как галочка), у ипсилон
  внизу есть небольшой хвостик-крючок (ближе к форме `u`). Использовать оба
  в одном задании безопасно.
- `ο` (омикрон) не используй вообще — на письме неотличим от `o`/`0`, в
  физике эта буква и так практически не встречается.
- Заглавные формы почти всех греческих букв, у которых нет своего
  уникального начертания (Α Β Ε Ζ Η Ι Κ Μ Ν Ο Ρ Τ Χ), тоже совпадают с
  латинскими A B E Z H I K M N O P T X — именно поэтому в физике эти буквы
  почти всегда пишут строчными, а не заглавными (это уже учтено в таблице
  выше).
- Остальные строчные пары (`ρ`/p, `τ`/t, `χ`/x, `υ`/u, `ι`/i) на глаз
  различимы в наших шрифтах — их можно использовать как обычно.

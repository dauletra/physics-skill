# `choice` — выбор варианта

Проверить понимание: один правильный вариант или несколько.

```json
{
  "type": "task",
  "blocks": [
    { "type": "text", "body": "Как меняется скорость при равноускоренном движении?" },
    {
      "type": "choice",
      "select": "single",
      "options": [
        { "text": "Скорость постоянна" },
        { "text": "Скорость растёт равномерно", "correct": true },
        { "text": "Тело покоится" }
      ]
    }
  ]
}
```

| поле | обяз. | значения |
|---|---|---|
| `options` | да | варианты; `correct: true` — инлайн у правильного |
| `select` | нет | `single` (по умолчанию) — ровно один `correct`; `multiple` — хотя бы один |

Варианты печатаются буквами а), б), в); в секции «Ответы» стоит та же буква.
Отсюда предел в 28 вариантов и запрет на два одинаковых — общие правила
набора (`document.md`).

При `multiple` над списком печатается подсказка «Отметьте все подходящие
варианты» — иначе ученику неоткуда узнать, что верных больше одного:

```json
{
  "type": "task",
  "blocks": [
    { "type": "text", "body": "Какие из перечисленных величин — векторные?" },
    {
      "type": "choice",
      "select": "multiple",
      "options": [
        { "text": "Путь" },
        { "text": "Скорость", "correct": true },
        { "text": "Масса" },
        { "text": "Ускорение", "correct": true }
      ]
    }
  ]
}
```

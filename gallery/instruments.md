# Приборы со шкалой

Компонент `instrument` — измерительный прибор с настоящей шкалой и, если
нужно, с показанием (`value`). Основной сценарий — задачи на снятие
показаний, цену деления и погрешность: прибор задаётся диапазоном
(`min`/`max`), ценой деления (`step`) и видом (`kind`).

Видов 15, геометрий шкалы — 7 семейств:

| Семейство | Виды (`kind`) | Предел числа делений |
|---|---|---|
| `strip` | `ruler` | 150 |
| `column` | `cylinder`, `thermometer`, `dynamometer` | 60 |
| `dial` | `ammeter`, `voltmeter`, `manometer`, `scale_dial`, `speedometer` | 60 |
| `clock` | `stopwatch` | 150 |
| `vernier` | `caliper` (нониус) | 40 |
| `balance` | `balance` (рычажные весы с гирями) | техн. |
| `digital` | `multimeter`, `digital_scale`, `digital_stopwatch` | техн. |

Ограничения вида:

* **`step` обязан делить диапазон нацело** — шкала с «половиной деления» на
  краю не бывает, это ошибка валидации;
* пределы числа делений выше — про читаемость: слишком плотные штрихи
  сливаются после масштабирования под ширину семейства;
* **кратность `value` цене деления не проверяется намеренно** — показание
  между штрихами и есть суть задач на погрешность отсчёта. Исключение —
  цифровое табло: оно «между штрихами» не показывает, там `value` обязано
  быть кратно дискретности;
* `label_step` (свой шаг подписей) работает только там, где штрихи есть, —
  на весах и цифровом табло это ошибка, а не игнорирование;
* `accuracy_class` рисуется только на стрелочных приборах (семейство
  `dial`) и только из ряда стандартных классов;
* **микрометр пока не поддержан** — он в списке запланированных.

Полный разбор видов, типичные школьные шкалы и задачи на погрешности —
в [`artifacts/instruments.md`](../reference/artifacts/instruments.md).

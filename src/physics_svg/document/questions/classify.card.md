# Классификация

Распределить объекты по группам: величины на скалярные и векторные, явления
по разделам физики, вещества по агрегатному состоянию.

Можно добавить группу, в которую ничего не попадает, — проверка на
внимательность.

**Что сказать Claude**

- «раздели величины на скалярные и векторные»
- «распредели явления по разделам физики»
- «три группы, в одну ничего попасть не должно»

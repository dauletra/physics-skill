# Разбор задачи

Образцовое решение на экране: условие, шаги, ответ. Шаги открываются по
одному, поэтому класс идёт за мыслью, а не читает готовое решение вперёд
учителя.

**Что сказать Claude**

- «разбери типовую задачу на слайде, по шагам»
- «покажи образец решения перед самостоятельной»
- «добавь разбор с графиком: найти ускорение по наклону»

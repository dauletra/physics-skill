# `frames` — одно движение в двух системах отсчёта

Два кадра рядом: слева — как видит пассажир носителя, справа — как видит
наблюдатель на земле. Задаётся движение **в системе носителя**; траектория
во втором кадре **вычисляется** преобразованием Галилея и автором не
пишется.

```json
{
  "type": "frames",
  "motion": "toss",
  "rise": 3,
  "shift": 8,
  "carrier": "вагон",
  "ground": "земля",
  "marks": 5,
  "grid": true,
  "caption": "1 клетка = 1 м"
}
```

| поле | обяз. | значения |
|---|---|---|
| `motion` | да | `still`, `uniform`, `toss`, `drop` — закон движения тела в системе носителя |
| `shift` | да | сколько клеток проезжает носитель за то же время; знак задаёт сторону, ноль запрещён |
| `carrier` | да | подпись первого кадра: «вагон», «самолёт», «тележка» |
| `ground` | да | подпись второго кадра: «земля», «дорога», «перрон» |
| `travel` | для `uniform` | `[dx, dy]` — смещение тела в своём кадре, в клетках |
| `rise` | для `toss` и `drop` | высота подъёма или падения, в клетках |
| `marks` | нет | сколько положений тела показать, 3–12; по умолчанию 5 |
| `grid` | нет | клетчатый фон, чтобы длины можно было сосчитать |
| `axes` | нет | оси `x` и `y` каждой системы отсчёта из её начала |
| `caption` | нет | подпись под рисунком: «1 клетка = 1 м» |

## Четыре движения

| `motion` | что рисует | сюжет |
|---|---|---|
| `still` | тело покоится на носителе | относительность покоя: чемодан на полке, груз на тележке |
| `uniform` | равномерное смещение на `travel` | пассажир идёт по вагону, человек на эскалаторе |
| `toss` | брошено вверх на `rise` и вернулось | мяч в едущем вагоне — в кадре земли выходит парабола |
| `drop` | падает с высоты `rise` | груз с самолёта, камень с движущейся платформы |

**Положения стоят через равные промежутки времени**, а не через равные
расстояния: у `toss` они сгущаются к вершине, у `drop` — к началу падения.
Из этого и получается парабола во втором кадре, поэтому «форму кривой»
задать нельзя и не нужно.

## Длина — в клетках

`rise`, `travel` и `shift` — числа клеток, как на векторной диаграмме.
Размер клетки подбирает рендерер, и он **общий для обоих кадров**: сравнивать
можно только то, что нарисовано в одном масштабе. Что клетка значит,
говорит `caption`.

Тело стартует на верхней грани носителя, носитель стоит на земле — кроме
`drop`, где он держится на высоте `rise`, а тело от него отделяется.

## Оси системы отсчёта

`axes: true` рисует в каждом кадре его собственные оси `x` и `y` с началом
в той точке, где тело было в начале. В обоих кадрах начало одно и то же —
при первой метке оба начала совпадают, — и дальше видно главное: одно из
них стоит, а носитель уезжает от него вместе со своим.

Ставь `axes`, когда речь о координате и начале отсчёта: «относительно чего
покоится», «чему равна координата тела в каждой системе». Для задач, где
считают только расстояния, достаточно `grid`.

Чисел на осях нет: цена деления — клетка, длины считают по сетке.

## Правила

- **`shift` не может быть нулём.** Носитель, который не движется
  относительно второй системы отсчёта, даёт два одинаковых кадра.
- **Поле принадлежит своему движению.** `travel` — только у `uniform`,
  `rise` — только у `toss` и `drop`; лишнее поле схема отвергает, а не
  игнорирует.
- **Раскладку кадров (рядом или друг под другом) выбирает рендерер** по их
  пропорциям. Поля для этого нет.
- Носитель рисуется платформой на колёсах — не вагоном, не самолётом и не
  лодкой. Какой это предмет, говорит подпись кадра.

## Чего тут нет

- **Ускоренных систем отсчёта.** `shift` — равномерный сдвиг; вагон,
  который разгоняется, и силы инерции этот тип не рисует.
- **Оси времени.** По обеим осям здесь длина. Как только по одной из них
  откладывается время, это `graph`, а не `frames`.
- **Носителя-среды.** Река и воздух платформой не рисуются: лодка с
  течением и самолёт с ветром — это сложение скоростей, то есть `vectors`.
- **Стрелок скорости.** Векторы на траекторию не накладываются — рядом
  ставится отдельная диаграмма `vectors`.
- **Третьего кадра** и совмещённых осей K и K′.

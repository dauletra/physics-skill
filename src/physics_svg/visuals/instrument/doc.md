# `instrument` — прибор со шкалой

Пятнадцать видов приборов. Задаются **данные измерения**, не рисунок:
диапазон, цена деления, показание. Сколько штрихов подписать и как
расположить корпус — решает рендерер.

```json
{
  "type": "instrument",
  "kind": "cylinder",
  "unit": "мл",
  "min": 0,
  "max": 250,
  "step": 10,
  "value": 175,
  "caption": "Мензурка"
}
```

| поле | обяз. | смысл |
|---|---|---|
| `kind` | да | вид прибора (список ниже) |
| `unit` | да | единица: `«см»`, `«А»`, `«°C»` |
| `min`, `max` | да | начало и предел шкалы |
| `step` | да | **цена деления** — данное задачи, всегда явно |
| `value` | нет | показание; без него прибор «на нуле» |
| `label_step` | нет | шаг подписанных штрихов в единицах величины |
| `caption` | нет | подпись под рисунком |

## Виды

| `kind` | прибор | `kind` | прибор |
|---|---|---|---|
| `ruler` | линейка с бруском | `stopwatch` | механический секундомер |
| `cylinder` | мензурка | `caliper` | штангенциркуль с нониусом |
| `thermometer` | термометр | `balance` | рычажные весы с гирями |
| `dynamometer` | динамометр | `multimeter` | цифровой мультиметр |
| `ammeter` | амперметр | `digital_scale` | электронные весы |
| `voltmeter` | вольтметр | `digital_stopwatch` | электронный секундомер |
| `manometer` | манометр | `scale_dial` | циферблатные весы |
| `speedometer` | спидометр | | |

## Правила шкалы

- `step` должен укладываться в `max − min` нацело, делений — от 2 до предела
  вида (150 у линейки и секундомера, 60 у столбика и дуги, 40 у
  штангенциркуля).
- **Показание между штрихами разрешено** и это норма: на нём стоят задачи о
  погрешности отсчёта. Исключения — цифровое табло (показание кратно
  дискретности) и штангенциркуль (кратно точности нониуса).
- `label_step` задавай, только когда шаг подписей — часть условия («определи
  цену деления»). Иначе рендерер сам подберёт круглый шаг.

## Задачи на погрешности

- `accuracy_class` — класс точности по ГОСТ 8.401 (0.05, 0.1, 0.2, 0.5, 1.0,
  1.5, 2.5, 4.0), печатается числом в углу шкалы стрелочного прибора.
  Приведённая погрешность: Δ = класс × предел / 100.
- `ranges` — два предела двухпредельного амперметра/вольтметра: на одной
  дуге две шкалы и три клеммы. `min`/`max`/`step` описывают **внешнюю**
  шкалу большего предела; `min` ≤ 0 (заход в минус разрешён).
- `vernier` — число делений нониуса штангенциркуля: 10 → 0,1 мм, 20 →
  0,05 мм. Точность на рисунке не печатается: её выводит ученик.
- `weights` — гири на правой чашке рычажных весов (до 4, повторы разрешены);
  `step` там означает наименьшую гирю набора, `max` — предел взвешивания.
  Весы всегда рисуются в равновесии: рисунок ставит задачу, согласованность
  масс — дело условия.

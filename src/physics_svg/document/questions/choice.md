# `choice` — выбор варианта

Проверить понимание: один правильный вариант или несколько.

```json
{
  "type": "choice",
  "select": "single",
  "options": [
    { "text": "Скорость постоянна" },
    { "text": "Скорость растёт равномерно", "correct": true },
    { "text": "Тело покоится" }
  ]
}
```

| поле | обяз. | значения |
|---|---|---|
| `options` | да | варианты; `correct: true` — инлайн у правильного |
| `select` | нет | `single` (по умолчанию) — ровно один `correct`; `multiple` — хотя бы один |

Варианты печатаются буквами а), б), в); в секции «Ответы» стоит та же
буква. При `multiple` над списком печатается подсказка «Отметьте все
подходящие варианты» — иначе ученику неоткуда узнать, что верных больше
одного.

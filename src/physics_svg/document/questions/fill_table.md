# `fill_table` — пропуски в таблице

Достроить таблицу: досчитать величину, дописать единицу, заполнить колонку.

```json
{
  "type": "task",
  "blocks": [
    { "type": "text", "body": "Тело разгоняется из состояния покоя равноускоренно. Заполните пропуски в таблице." },
    {
      "type": "fill_table",
      "headers": ["t, с", "υ, м/с", "S, м"],
      "rows": [
        ["0", "0", "0"],
        ["2", "10", { "answer": "10" }],
        ["4", { "answer": "20" }, { "answer": "40" }]
      ]
    }
  ]
}
```

| поле | обяз. | смысл |
|---|---|---|
| `headers` | да | заголовки колонок |
| `rows` | да | ячейка — строка или пропуск `{ "answer": … }` |
| `bank` | нет | слова для выбора, той же строкой, что у `fill_text` |

Форма полей — та же, что у компонента `table`; пропуск заменяет содержимое
ячейки, ответ лежит инлайн. Хотя бы одна ячейка должна быть пропуском.
Условие обязано давать то, из чего пропуски считаются: без «разгоняется
равноускоренно» таблицу не заполнить.

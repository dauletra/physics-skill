# Открытый вопрос

Ученик пишет ответ сам: расчёт с решением, объяснение, короткий ответ словом
или числом.

Самый частый вид. Рядом обычно ставится место для записи — несколько строк
под решение или строчка «Ответ: ___».

**Что сказать Claude**

- «пять задач на расчёт скорости, под каждой три строки для решения»
- «спроси, почему тело плавает, оставь место на полстраницы»
- «короткий ответ числом, строчки хватит»

# `objectives` — цели урока

Слайд «сегодня научимся…»: короткий список того, что класс сможет после
урока.

```template
basic
```

| поле | обяз. | значения |
|---|---|---|
| `items` | да | цели, по строке на каждую; хотя бы одна |

Цель формулируется действием ученика («читать», «находить»), а не темой
(«график скорости») — так слайд отвечает на вопрос «зачем», а не «о чём».

# `rank` — упорядочивание

Расставить по порядку: этапы процесса, величины по возрастанию, шаги
решения.

```json
{
  "type": "rank",
  "items": [
    { "text": "Тело падает", "position": 3 },
    { "text": "Тело покоится на высоте", "position": 1 },
    { "text": "Нить пережигают", "position": 2 }
  ]
}
```

| поле | обяз. | смысл |
|---|---|---|
| `items` | да | пункты; `position` — правильное место, от 1 |

**Порядок массива — это порядок показа** (перемешанный), а `position` —
правильный. Позиции должны быть перестановкой 1..N без пропусков. У каждого
пункта печатается квадратик под номер; ответ — номера пунктов в правильном
порядке.

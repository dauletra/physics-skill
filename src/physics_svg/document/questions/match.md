# `match` — сопоставление

Связать термины с определениями, величины с единицами, приборы с тем, что
они измеряют.

```json
{
  "type": "task",
  "blocks": [
    { "type": "text", "body": "Сопоставьте величины и единицы их измерения." },
    {
      "type": "match",
      "left": [
        { "text": "Скорость", "match": "ms" },
        { "text": "Ускорение", "match": "ms2" }
      ],
      "right": [
        { "id": "ms", "text": "м/с" },
        { "id": "ms2", "text": "м/с²" },
        { "id": "m", "text": "м" }
      ]
    }
  ]
}
```

| поле | обяз. | смысл |
|---|---|---|
| `left` | да | пункты с ссылкой `match` на `right[].id` |
| `right` | да | набор вариантов с явными `id`; лишние — дистракторы |

Связь идёт по `id`, а не по позиции: перестановка любого столбца ничего не
ломает. Левый столбец нумеруется, правый — буквами; ответ выглядит как
`1-а, 2-б`. Правый столбец — набор в смысле «Набор, из которого выбирает
ученик» (`document.md`): лишние варианты дистракторы, один вариант может
подойти нескольким пунктам слева.

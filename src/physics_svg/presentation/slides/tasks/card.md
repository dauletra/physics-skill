# Набор задач

Две-четыре задачи на одном экране: класс работает по рядам или в парах, а
не смотрит на доску. У каждой задачи свой ответ, ряд ответов стоит по низу
слайда.

В HTML-плеере ответ каждой задачи спрятан под своей плашкой и открывается
щелчком; в файле PowerPoint ответы пока видны сразу — если показывать их
классу рано, проще собрать слайд без `answer`. Картинки помещаются только
при двух задачах: три и четыре — это уже два слайда.

- «слайд с тремя задачами для работы в парах»
- «дай четыре задачи на экран, ответы спрячь»
- «две задачи с графиками рядом»

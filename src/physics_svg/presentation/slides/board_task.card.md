# Задача у доски

Условие задачи на весь экран — для решения у доски, пока класс следит.
Ответ виден только учителю, пока он не решит его показать. Серия задач —
несколько слайдов, по задаче на каждый.

**Что сказать Claude**

- «добавь две задачи для решения у доски»
- «задачу с графиком — на слайд, с ответом для меня»
- «после объяснения — задача на закрепление у доски»

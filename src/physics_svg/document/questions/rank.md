# `rank` — упорядочивание

Расставить по порядку: этапы процесса, величины по возрастанию, шаги
решения.

```json
{
  "type": "task",
  "blocks": [
    { "type": "text", "body": "Груз висит на нити. Расставьте события в правильном порядке (1 — первое)." },
    {
      "type": "rank",
      "items": [
        { "text": "Тело падает", "position": 3 },
        { "text": "Тело покоится на высоте", "position": 1 },
        { "text": "Нить пережигают", "position": 2 }
      ]
    }
  ]
}
```

| поле | обяз. | смысл |
|---|---|---|
| `items` | да | пункты; `position` — правильное место, от 1 |

**Порядок массива — это порядок показа** (перемешанный), а `position` —
правильный. Позиции должны быть перестановкой 1..N без пропусков. У каждого
пункта печатается квадратик под номер; в «Ответах» пункты перечислены в
правильном порядке вместе с их текстом. В условии скажи, что означает
первый номер, — «1 — первое событие», «1 — наименьшая скорость».

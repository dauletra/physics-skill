# `board_task` — задача у доски

Задача, которую ученик решает у доски, пока класс следит. Это не вопрос
рабочего листа: здесь нет места под запись и нумерации, а ответ — подсказка
учителю, и когда его показать, решает показ, а не спека.

Ответ спрятан и появляется по щелчку — отдельной строкой внизу слайда.

```template
basic
```

| поле | обяз. | значения |
|---|---|---|
| `text` | да | условие задачи |
| `visual` | нет | иллюстрация к условию |
| `answer` | нет | ответ для учителя; без него слайд — просто условие |

Задача по графику или рисунку — та же спека визуала, что везде:

```template
with-visual
```

Задача на отсчёт по шкале — та же спека прибора, что в документе; `step` в
ней и есть цена деления, а `label_step` ставят, когда её ищет ученик:

```template
with-instrument
```

Задача по чертежу сил — та же векторная диаграмма, что в документе. Поле
`resultant` в ней не задают, если равнодействующую ищет ученик: это подпись
уже нарисованной стрелки, а не просьба её вычислить.

```template
with-vectors
```

**`answer` здесь нужен почти всегда** — в отличие от `example`, шагов у
задачи нет, и без ответа учителю нечего сверить. Не ставят его тогда, когда
прятать нечего: результат — построение, чертёж или вывод формулы, и он
появляется на доске, а не на экране.

```template
without-answer
```

Серия задач для доски — несколько слайдов подряд, по задаче на слайд:
у доски решают по одной.

# `title` — титульный слайд

Открывает урок: тема крупно, строка контекста под ней.

```json
{
  "type": "title",
  "text": "Равноускоренное движение",
  "subtitle": "Физика, 9 класс"
}
```

| поле | обяз. | значения |
|---|---|---|
| `text` | да | тема урока |
| `subtitle` | нет | строка под темой: предмет, класс |

Если титульного слайда нет, плеер показывает `title` из манифеста. Дату,
фамилию учителя и номер школы слайд не несёт — как и лист, презентация не
подписывает себя сама; нужна строка контекста — это `subtitle`.

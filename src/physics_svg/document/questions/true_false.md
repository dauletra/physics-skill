# `true_false` — верно или неверно

Разобрать серию утверждений: проверка формулировок и типовых заблуждений.

```json
{
  "type": "true_false",
  "statements": [
    { "text": "Скорость — векторная величина", "answer": true },
    { "text": "Путь может быть отрицательным", "answer": false }
  ]
}
```

| поле | обяз. | смысл |
|---|---|---|
| `statements` | да | утверждения; `answer` — правильный вердикт инлайн |

У каждого утверждения печатаются два квадратика «Верно»/«Неверно». В ответе
— строка вида `1 — Верно, 2 — Неверно` по номерам утверждений.

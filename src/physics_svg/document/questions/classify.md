# `classify` — классификация

Распределить объекты по группам: величины на скалярные и векторные, явления
по разделам, вещества по агрегатному состоянию.

```json
{
  "type": "task",
  "blocks": [
    { "type": "text", "body": "Распределите явления по разделам физики: впишите название раздела рядом с каждым явлением." },
    {
      "type": "classify",
      "categories": ["Механика", "Тепловые явления", "Электрические явления"],
      "items": [
        { "text": "Свободное падение камня", "category": "Механика" },
        { "text": "Плавление льда", "category": "Тепловые явления" },
        { "text": "Движение по окружности", "category": "Механика" }
      ]
    }
  ]
}
```

| поле | обяз. | смысл |
|---|---|---|
| `categories` | да | названия групп; группа без объектов допустима — дистрактор |
| `items` | да | объекты; `category` — правильная группа инлайн |

Группы печатаются строкой «Группы:» над списком — повторять их в соседнем
`text` не нужно. Это набор в смысле `document.md`: пустая группа — дистрактор,
одинаковых групп быть не может, в одну группу попадает сколько угодно
объектов. Ниже идут объекты, у каждого прочерк под название группы. В
«Ответах» — строка на группу, в авторском порядке `categories`; пустая группа
показывается прочерком (в примере это «Электрические явления»).

# Локализация: русский/казахский

Два независимых механизма — не путай их:

1. **Служебные подписи листа** ("Школа/класс:", "Ответ:", "Верно"/"Неверно",
   подписи тулбара, футер, суффикс баллов) — переключаются автоматически
   через `meta.json → "language"` (`"ru"` или `"kk"`). Рендерер сам берёт
   нужный вариант из словарей `STRINGS` (Python) и `UI_STRINGS` (JS) в
   `scripts/render_worksheet.py`. Ничего вручную переводить не нужно —
   просто поставь правильное значение `language`.
2. **Содержимое заданий** (`prompt`, `answer`, варианты, подписи графика и
   т.д.) — рендерер этого не переводит и не может: перевод физического
   текста делаешь ты (Claude) вручную в диалоге, по запросу учителя.

## Воркфлоу перевода содержимого

Когда учитель просит казахскую (или обратно русскую) версию уже готового
черновика:

1. Создай **новую соседнюю папку**, например `kinematics-9th-grade-kk/`
   рядом с `kinematics-9th-grade/`. **Не редактируй и не перезаписывай
   оригинал.**
2. Скопируй `meta.json`, поставь `"language": "kk"`, переведи `title` и
   `instructions`. `subject` (например "Физика") часто не меняется — но
   проверь для конкретного предмета.
3. Для каждого `tasks/task-NN.json` — скопируй файл и переведи только
   текстовые поля:
   - `prompt`, `answer`
   - `options` (`multiple_choice`), `statements[].text` (`true_false`)
   - `left_items`/`right_items` (`matching`)
   - `chart_spec.x_label`/`y_label`/`series[].label` (`chart`)
   - `svg_snippet.params.*_label` (`illustration`)
   - `blanks` значения, если это слова, а не просто числа (`fill_blank_text`)

   Не трогай структурные и числовые поля: `id`, `type`, `points`,
   `solution_lines`, диапазоны/`chart_type`/`style`, `svg_snippet.name`,
   `correct`, `visual_width`/`visual_position`/`variants_layout`, ключи
   `answer_map`/`answers` (сами буквы/номера-ключи, не значения).
4. Пример готового результата — `examples/kinematics-9th-grade-kk/`
   (переведены `task-01` и `task-04` из основного примера
   `examples/kinematics-9th-grade/`) — ориентируйся на него по формату.

## Что не меняется при переводе

- Условные обозначения из `symbols.md` (греческие буквы, `υ` для скорости,
  приоритет текст→`<sup>`/`<sub>`→LaTeX) действуют одинаково в обоих
  языках — переводи окружающую прозу, а не нотацию.
- Единицы СИ (м, с, кг, Н, Дж, Вт) в примерах выше не менялись между
  русским и казахским — но это не гарантия для любой темы: в казахском
  физическом образовании возможны свои устоявшиеся обозначения. Если не
  уверен — сверься или спроси учителя, не угадывай.

## Важно: это разовый снимок, не живая синхронизация

Переведённая папка — полностью независимая копия. Правки в оригинале
(русском или казахском) **не подтягиваются** в другую папку автоматически —
если учитель поменял текст задания после того, как перевод уже сделан, и
хочет, чтобы перевод тоже обновился — это отдельный запрос ("обнови перевод
задания 3"), а не что-то происходящее само.

**Никогда не храни оба языка внутри одного `task-NN.json`** (никаких полей
вида `prompt_ru`/`prompt_kk` рядом друг с другом) — только полностью
отдельные папки-черновики с собственными `meta.json`/`tasks/`. Это защищает
основной принцип проекта: один task-файл — один явный источник правды для
одного языка.

# `classify` — классификация

Распределить объекты по группам: величины на скалярные и векторные, явления
по разделам, вещества по агрегатному состоянию.

```json
{
  "type": "classify",
  "categories": ["Скалярные", "Векторные"],
  "items": [
    { "text": "Масса", "category": "Скалярные" },
    { "text": "Сила", "category": "Векторные" },
    { "text": "Время", "category": "Скалярные" }
  ]
}
```

| поле | обяз. | смысл |
|---|---|---|
| `categories` | да | названия групп; группа без объектов допустима — дистрактор |
| `items` | да | объекты; `category` — правильная группа инлайн |

Категории перечисли в соседнем `text` или списком — в теле вопроса
печатаются только объекты с прочерком под ответ. Сводка в «Ответах» идёт в
авторском порядке `categories`; пустая группа показывается прочерком.

# `open` — открытый вопрос

Ответ свободной формы: расчёт с решением, объяснение, короткий ответ словом.
«Найди и исправь ошибку» — тот же вид, отличие только в условии.

```json
{
  "type": "task",
  "blocks": [
    { "type": "text", "body": "Автомобиль движется равномерно со скоростью υ = 72 км/ч. Какой путь он пройдёт за 15 минут?" },
    { "type": "open", "answer": "S = 18 км" },
    { "type": "paper", "ruling": "lines", "rows": 3 }
  ]
}
```

| поле | обяз. | смысл |
|---|---|---|
| `answer` | нет | правильный ответ; без него вопрос устный |
| `explanation` | нет | пояснение к ответу; требует `answer` |

**Тело этого вопроса пусто.** Условие несёт соседний `text`, место под
ответ — соседний `paper` или `answer_line`, как в примере. Почти всегда
рядом должно стоять место для записи; исключение — когда одна разлиновка
стоит на несколько подпунктов сразу или отвечают устно.

# `example` — разбор задачи

Задача, которую разбирает учитель, пока класс следит за ходом решения. От
`board_task` отличается тем, что решение есть в данных: шаги идут списком,
и плеер вправе открывать их по одному.

```json
{
  "type": "example",
  "text": "Тело трогается с места и за 5 с разгоняется до 10 м/с. Найдите путь.",
  "steps": [
    "Движение равноускоренное: $v_0 = 0$, значит $S = \\frac{at^2}{2}$",
    "Ускорение: $a = \\frac{v - v_0}{t} = \\frac{10}{5} = 2$ м/с²",
    "Путь: $S = \\frac{2 \\cdot 25}{2} = 25$ м"
  ],
  "answer": "25 м"
}
```

| поле | обяз. | значения |
|---|---|---|
| `text` | да | условие разбираемой задачи |
| `steps` | да | шаги решения, минимум один; по строке на шаг |
| `answer` | нет | ответ отдельной строкой |
| `visual` | нет | иллюстрация к условию |

**Шаг — это строка, а не абзац с переносами.** Плеер открывает шаги по
одному, и знать, где кончается шаг, он может только из данных: разбор,
слепленный в один `text`, показать по шагам нельзя.

Разбор с картинкой — та же спека визуала, что везде:

```json
{
  "type": "example",
  "text": "По графику найдите ускорение на первом участке.",
  "steps": [
    "Берём две точки участка: $(0; 0)$ и $(3; 6)$",
    "Ускорение — наклон: $a = \\frac{6 - 0}{3 - 0} = 2$ м/с²"
  ],
  "visual": {
    "type": "graph",
    "x_label": "t, с",
    "y_label": "υ, м/с",
    "x_range": [0, 6],
    "y_range": [0, 8],
    "series": [
      { "label": "υ(t)", "points": [[0, 0], [3, 6], [6, 6]] }
    ]
  },
  "answer": "2 м/с²"
}
```

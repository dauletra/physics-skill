# `example` — разбор задачи

Задача, которую разбирает учитель, пока класс следит за ходом решения. От
`board_task` отличается тем, что решение есть в данных: шаги идут списком,
и плеер вправе открывать их по одному.

```template
steps
```

| поле | обяз. | значения |
|---|---|---|
| `text` | да | условие разбираемой задачи |
| `steps` | да | шаги решения, минимум один; по строке на шаг |
| `answer` | нет | итог, которого нет в шагах; см. правило ниже |
| `visual` | нет | иллюстрация к условию |

**Шаг — это строка, а не абзац с переносами.** Плеер открывает шаги по
одному, и знать, где кончается шаг, он может только из данных: разбор,
слепленный в один `text`, показать по шагам нельзя.

**`answer` — только то, чего в шагах нет.** Шаги и ответ показываются
по-разному: шаги открывает стрелка, шаг за шагом, а ответ спрятан под
плашкой и открывается щелчком по ней. Поэтому в разборе, который кончается
числом, поля `answer` быть не должно: плашка «Ответ» над строкой, где это
число уже вычислено, ничего не прячет и обесценивает плашку там, где под
ней действительно ответ. Ставь `answer` в разборе, только когда шаги —
рассуждение, а число приходит в конце (пример ниже).

Разбор с картинкой — та же спека визуала, что везде. Здесь `answer` на
месте: шаги показывают, как читать график, а число появляется только в нём.

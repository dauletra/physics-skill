# Разделитель этапа

Слайд с названием этапа урока во весь экран. Делит презентацию на части и
даёт плееру список этапов: по клавише Esc открывается перечень, из которого
можно перепрыгнуть к нужному месту урока.

**Что сказать Claude**

- «раздели урок на этапы: новая тема, закрепление, итог»
- «поставь разделитель перед задачами»
- «добавь слайд-заставку «Закрепление»»

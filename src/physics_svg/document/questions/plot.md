# `plot` — построение графика

Оси заданы, кривую строит ученик. Правильный график печатается в секции
«Ответы» на тех же осях.

```json
{
  "type": "task",
  "blocks": [
    { "type": "text", "body": "Скорость тела растёт равномерно: при t = 0 она равна 2 м/с, при t = 6 с — 12 м/с. Постройте график скорости от времени; начальная точка уже отмечена." },
    {
      "type": "plot",
      "x_label": "t, с",
      "y_label": "υ, м/с",
      "x_range": [0, 6],
      "y_range": [0, 12],
      "grid": "fine",
      "given": [{ "points": [[0, 2]] }],
      "answer": [{ "points": [[0, 2], [6, 12]] }]
    }
  ]
}
```

| поле | обяз. | смысл |
|---|---|---|
| `x_label`, `y_label`, `x_range`, `y_range` | да | как у компонента `graph` |
| `answer` | да | правильные серии |
| `given` | нет | серии, уже нарисованные ученику (например, одна точка) |
| `chart_type`, `grid` | нет | как у `graph` |
| `x_step`, `x_label_step`, `y_step`, `y_label_step` | нет | как у `graph`: цена деления и шаг подписей |

Ставь `grid: "fine"` — по мелкой сетке точку откладывают точнее. Если клетка
названа условием («цена деления 2 м/с»), задай шаг явно: ученик строит по той
сетке, о которой говорит задание. Данные, по которым строят график, несёт
условие: оси сами по себе не задание. Если оси задавать не нужно и ученик
рисует их сам — это не `plot`, а компонент `paper` с разлиновкой `mm`.

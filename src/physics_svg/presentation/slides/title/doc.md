# `title` — титульный слайд

Открывает урок: тема крупно, строка контекста под ней.

```template
basic
```

| поле | обяз. | значения |
|---|---|---|
| `text` | да | тема урока |
| `subtitle` | нет | строка под темой: предмет, класс |

Титульный слайд ставят сами: `title` из манифеста уходит в свойства файла
и на экран не попадает — без этого слайда урок начинается сразу с дела. Дату,
фамилию учителя и номер школы слайд не несёт — как и лист, презентация не
подписывает себя сама; нужна строка контекста — это `subtitle`.

Предмет и класс учитель называет не всегда. Не названы — слайд обходится
одной темой: выдуманный класс на титуле хуже, чем его отсутствие.

```template
topic-only
```

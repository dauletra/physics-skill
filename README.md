# physics-materials

[![CI](https://github.com/dauletra/physics-skill/actions/workflows/ci.yml/badge.svg)](https://github.com/dauletra/physics-skill/actions/workflows/ci.yml)

Claude-скилл для учителей физики: собирает рабочие листы, карточки с
задачами, конспекты и объяснения — и рисует к ним SVG-иллюстрации.

Учитель описывает словами, что нужно; Claude составляет короткое
JSON-описание документа, а вёрстку и рисунки делает детерминированный
рендерер. Поэтому все документы выглядят одинаково, а не так, как модель
запомнила прошлый раз.

**Сайт с галереей, примерами и установкой:**
<https://dauletra.github.io/physics-skill/>

## Для учителя

1. Скачать [`physics-materials-skill.zip`](https://dauletra.github.io/physics-skill/assets/physics-materials-skill.zip)
   — свежая сборка, либо конкретная версия
   [из релизов](https://github.com/dauletra/physics-skill/releases).
2. Загрузить в Claude: **Settings → Capabilities → Skills**.
3. Написать в диалоге: «сделай рабочий лист по кинематике для 9 класса…».

Ставить ничего не нужно, интернет для сборки не нужен.

## Что умеет

- **Иллюстрации**: графики (линия, столбики, точки), 15 измерительных
  приборов со шкалой (линейка, мензурка, амперметр, штангенциркуль, весы,
  секундомер, цифровые табло…), пять разлиновок бумаги. Любую можно
  получить отдельным SVG-файлом для презентации.
- **Девять видов заданий**: открытый вопрос, тест, сопоставление, пропуски
  в тексте и в таблице, построение графика, верно/неверно, упорядочивание,
  классификация. Пункты а)/б)/в), баллы, сквозная нумерация.
- **Раздел «Ответы»** в конце документа и раздаточный вариант без него.
- Формулы, греческие буквы, индексы и степени.

Схемы опыта, электрические цепи и чертежи пока не поддерживаются.

## Для разработчика

```bash
pip install -e ".[dev,docs]"
python -m pytest tests -q     # тесты
python tools/dev.py           # живой просмотр иллюстраций и примера
python tools/build_skill.py   # собрать бандл
python tools/build_site.py && zensical build --strict
```

Пакет `physics_svg` не имеет зависимостей: скилл должен работать офлайн, в
любой песочнице, без установки. Это проверяется тестом, который сверяет
импорты собранного бандла со списком стандартной библиотеки.

Новый тип иллюстрации — одна папка `src/physics_svg/visuals/<тип>/`
(модель, рендер, спеки-примеры, справочник для модели, карточка для
учителя). Реестр сам подхватит его в валидацию, JSON Schema, галерею,
golden-тесты, справочники бандла и библиотеку заготовок.

Устройство — [docs/architecture.md](docs/architecture.md), принципы схемы
данных — [docs/schema-design-principles.md](docs/schema-design-principles.md),
с чего начать — [docs/contribute.md](docs/contribute.md).

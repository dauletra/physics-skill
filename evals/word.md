# Word: чек-лист ручной проверки

Автотесты доказывают, что пакет собран правильно, и открывают его чужой
библиотекой. Чего они не доказывают — что **Word его откроет** и что лист в
нём выглядит так, как задумано. Word на непонравившийся пакет не говорит
ничего вразумительного, а на понравившийся молча чинит часть ошибок, и оба
исхода тест не отличает от нормы.

Поэтому: один проход по этому листу на каждой фазе Word-бэкенда
([план](../docs/word-export.md)) и перед каждым выпуском, который его
трогает. Промах — дописать строку в «Журнал», дословно.

## Как получить файл

```bash
python -m physics_svg.cli build <папка-черновика> --format docx
```

Проверять в **Word** — адресат один, других редакторов скилл не
поддерживает. Плюс предпросмотр печати: лист делается для бумаги.

## Что смотреть

### Открытие

- [ ] Word открывает файл без диалога «в документе обнаружены ошибки»
- [ ] в свойствах файла стоит название документа

### Страница

- [ ] A4, поля примерно 20 мм по бокам и 15 сверху и снизу
- [ ] шрифт — тот, что заявлен в `styles.py`; если подставился другой,
      проверить, не разъехались ли пропуски и таблицы
- [ ] предпросмотр печати: ничего не уезжает за поля

### Разметка

- [ ] номера заданий стоят в поле слева, текст выровнен по колонке
- [ ] буквы подзаданий отбиты дальше номера
- [ ] маркеры списка (`а)`, `1.`) стоят в своём поле, текст не наезжает
- [ ] строка «Верно/Неверно» — квадратики у правого края, текст слева
- [ ] квадратик `☐` виден, а не показан как пустой прямоугольник или знак
      вопроса (это значит, что шрифта нет)
- [ ] пропуски под запись — сплошная линия нужной длины, не набор чёрточек
- [ ] «Ответ: ______» не переносится на следующую строку
- [ ] таблица: колонки равной ширины, шапка с заливкой
- [ ] таблица длиннее страницы: шапка повторяется на второй странице
- [ ] колонки (`row`) стоят рядом и не разъезжаются
- [ ] секция «Ответы» отделена линией, каждый ответ под своим номером

### Правки руками — то, ради чего формат и нужен

- [ ] в панели стилей видны русские имена: «Обычный», «Заголовок листа»,
      «Задание», «Ответ»…
- [ ] правка стиля «Обычный» (кегль или шрифт) меняет весь лист сразу
- [ ] правка стиля «Задание» меняет все задания и не трогает остального
- [ ] текст задания редактируется как обычный текст: номер не уезжает,
      отступ не сбрасывается
- [ ] удаление задания не ломает нумерацию соседей (номера литеральные —
      после правки их правит учитель, и это ожидаемо, см. план)

### Иллюстрации

Отдельный файл со всеми типами разом:

```bash
python tools/contact_sheet.py --docx
```

- [ ] график: оси со стрелками, засечки, подписи делений на своих местах
- [ ] подписи осей (`υ, м/с`) не наезжают на стрелку и не обрезаны
- [ ] индексы и степени (`υ<sub>0</sub>`, `м/с²`) — подстрочные и надстрочные,
      а не текст в одну строку
- [ ] прибор: шкала, цифры, стрелка; клеймо с разрядкой читается
- [ ] разлиновка: строки/клетка/миллиметровка нужного шага, поле не
      растянуто и не сжато по одной оси
- [ ] разлиновка на всю колонку тянется до правого поля, а линии не стали
      ни нитками, ни жирными
- [ ] векторная диаграмма: стрелки, дуги углов, пунктир построения
- [ ] картинка в колонке (`row`) вписана в свою половину, а не залезает
      на соседнюю
- [ ] щелчок по подписи выделяет **её**, а не весь рисунок: это фигуры, а
      не картинка, и подпись должна двигаться отдельно
- [ ] рисунок тянется за угол без потери качества
- [ ] печать: линии не пропали и не слились

### Чего быть не должно

- [ ] в раздаточном варианте (`--handout`) нет ни одного ответа
- [ ] нет пустых рамок на месте иллюстраций
- [ ] нет лишних пустых абзацев между блоками
- [ ] файл открывается за секунды: если документ с миллиметровкой думает
      долго, разлиновка развернулась в слишком много фигур

# `content` — объяснение

Рабочая лошадка урока: заголовок, абзац, список, иллюстрация — в любом
непустом сочетании. Как расположить их на экране, решает плеер.

```json
{
  "type": "content",
  "heading": "Скорость растёт линейно",
  "text": "При постоянном ускорении скорость меняется по закону $v = v_0 + at$: за каждую секунду она прибавляет одно и то же значение.",
  "visual": {
    "type": "graph",
    "x_label": "t, с",
    "y_label": "υ, м/с",
    "x_range": [0, 6],
    "y_range": [0, 12],
    "series": [
      { "label": "υ(t)", "points": [[0, 2], [6, 11]] }
    ]
  }
}
```

| поле | обяз. | значения |
|---|---|---|
| `heading` | нет | заголовок слайда |
| `text` | нет | абзац объяснения |
| `items` | нет | список, по строке на пункт |
| `visual` | нет | спека иллюстрации — та же, что в документе |

Хотя бы одно из `text`, `items`, `visual` обязательно: заголовок сам по
себе анонсирует объяснение, которого нет. Длинное объяснение — это
несколько слайдов `content`, а не один переполненный: слайд читают с
последней парты.

```json
{
  "type": "content",
  "heading": "Что понадобится",
  "items": [
    "формула скорости $v = v_0 + at$",
    "путь — площадь под графиком υ(t)",
    "перевод км/ч в м/с"
  ]
}
```

# Набор задач

Две-четыре задачи на одном экране: класс работает по рядам или в парах, а
не смотрит на доску. У каждой задачи свой ответ, ряд ответов стоит по низу
слайда.

Ответы открываются по очереди, с первой задачи: поток щелчков в PowerPoint
один, и выбрать из него ту задачу, до которой дошёл класс, нельзя. Если
класс решает вразнобой, ответы на экран лучше не выводить. Картинки
помещаются только при двух задачах: три и четыре — это уже два слайда.

- «дай четыре задачи на экран, ответы спрячь»
- «две задачи с графиками рядом»

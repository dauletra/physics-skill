# Триггеры скилла: журнал промахов

`description` в `skill/SKILL.md` — единственная часть скилла, которую модель
видит **до** того, как решит его применить. Проверить её автоматически
нельзя: прогон требует модели и сети, а пакет обязан собираться офлайн.
Поэтому проверка здесь ручная и накопительная.

**Как пользоваться.** Промахнулся скилл в живой работе — допиши строку в
таблицу, дословно, не приглаживая формулировку. Правишь `description` —
прочитай обе таблицы подряд и спроси себя по каждой строке: попадает ли
новый текст в этот случай и не задевает ли отрицательные. Это чек-лист
перед правкой, а не отчёт после неё.

Лимит `description` — 1024 символа, проверяется при сборке бандла. Место
ограничено: новую формулировку добавляют, обобщая соседнюю, а не приписывая
ещё одну строку в перечисление.

## Должен срабатывать

| формулировка | заметка |
|---|---|
| «сделай рабочий лист по теме давление, 7 класс» | базовый случай |
| «оформи эти задачи» + список задач | оформление готового |
| «собери задачи в один документ» | оформление готового |
| «сделай конспект по теме» | документ без заданий |
| «сделай одно задание по кинематике, сделай его контекстным» | **промах 2026-07-30**: нет слова «оформи», единственное число, «контекстное задание» не было названо |
| «сделай график зависимости υ(t)» в диалоге про задание | **промах 2026-07-30**: ушло в стороннюю рисовалку; сработала инерция — первая реплика диалога уже прошла мимо скилла |
| «составь задачу с графиком» | сочинение с нуля |
| «нужна задача на цену деления шкалы» | сочинение с нуля, без слова «задание» |
| «придумай пять задач на равноускоренное движение» | сочинение с нуля, множественное число |
| «сделай вариант без ответов» | `--handout` у уже собранного документа |
| «переделай второе задание», «добавь график в третье» | правка одного блока |
| «нарисуй мензурку со шкалой» | отдельная иллюстрация, без документа |
| «картинка динамометра для презентации» | отдельная иллюстрация, слово «задание» не звучит |
| «сделай лабораторную по измерению плотности» | документ другого жанра |

## Не должен срабатывать

| формулировка | почему |
|---|---|
| «объясни мне, как работает закон Ома» | ответ в диалог мне, а не материал ученику |
| «реши эту задачу» | нужен ответ, а не документ |
| «проверь решение ученика» | ни документа, ни иллюстрации |
| «нарисуй схему архитектуры проекта» | «нарисуй» есть, учебного материала нет |
| «сделай график продаж по кварталам» | график есть, ученика нет |
| правки в коде самого репозитория | скилл — продукт, а не инструмент разработки |

## Инерция диалога

Отдельно от формулировок: если первая реплика диалога прошла мимо скилла,
следующие остаются в том же режиме, даже когда сами по себе близки к
триггеру. Точность `description` этот эффект ослабляет, но не снимает —
снимает только явное упоминание скилла в первой реплике либо хук на стороне
среды. Считать это известным ограничением, а не поводом снова растить
перечисление формулировок.

# Выбор варианта

Тест: один правильный вариант из нескольких или сразу несколько.

Хорош для проверки понимания и для типичных заблуждений — неправильные
варианты стоит делать правдоподобными. Правильный ответ в листе никак не
помечен, он уходит в раздел «Ответы».

**Что сказать Claude**

- «тест из пяти вопросов по теме, по четыре варианта»
- «сделай так, чтобы верных было два, и предупреди об этом ученика»
- «первый вариант пусть будет типичной ошибкой»

# `tasks` — набор задач

Несколько задач на одном экране: по рядам, по вариантам, «решите в парах».
Класс видит их сразу все и работает параллельно — в этом отличие от
`board_task`, где задачу решают по одной у доски.

```template
basic
```

| поле | обяз. | значения |
|---|---|---|
| `tasks` | да | задачи: от двух до четырёх |
| `heading` | нет | заголовок: «Решите в парах» |

Поля задачи:

| поле | обяз. | значения |
|---|---|---|
| `text` | да | условие |
| `visual` | нет | иллюстрация к условию |
| `answer` | нет | ответ; у каждой задачи своя плашка |

**Одна задача — это `board_task`.** Набор из одной задачи — набор только на
бумаге: у доски решают по одной, и слайд под это уже есть.

**Ответы открываются по очереди, с первой задачи.** У каждой задачи своя
плашка, но поток щелчков в колоде один, и выбрать из него нельзя: щелчок
открывает следующий по счёту ответ, а не тот, до которого дошёл класс.
Поэтому набор, который решают вразнобой, собирают вовсе без `answer` —
ответы разбирают вслух:

```template
without-answers
```

**Номера задач слайд не несёт.** Номер — это место в списке, его рисует
показ; в данных его нет по той же причине, что и на листе.

**Сколько помещается.** Замерено на кадре, строк условия на каждую задачу:

| задач | без картинки | с картинкой |
|---|---|---|
| две | 9 | 2 |
| три | 3 | **не помещаются** |
| четыре | 3 | **не помещаются** |

Три и четыре задачи с иллюстрациями на экран не встают вовсе — на такое
уходит два слайда. Три коротких условия и четыре стоят одинаково: обе
раскладки идут в два ряда, и высоту ряда задаёт тот же кадр.

Два числа стоит прочитать вместе. **Девять строк без картинки** — это
запас: полоса ответов внизу занята, и всё равно остаётся почти весь
столбец. **Две строки с картинкой** — это предел, и он жёсткий: замер
показал, что при двух строках условия в ячейке читаются 23 иллюстрации
библиотеки из 35, а при трёх — 13. Задача по графику формулируется коротко
(«По графику найдите путь за первые 4 секунды»), остальное говорит рисунок.

Номера задач в `text` не пишут: они появляются сами. Задача с картинкой
занимает больше места — таких на экране помещается две, а не четыре:

```template
with-visual
```

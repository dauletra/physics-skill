# Пропуски в таблице

Таблица, в которой часть ячеек пустая: досчитать величину, дописать
единицу, заполнить колонку по формуле.

Хорошо ложится на «зависимость одной величины от другой» — ученик заодно
видит закономерность.

**Что сказать Claude**

- «таблица t, υ, s для равноускоренного движения, часть значений пропусти»
- «пусть заполнят колонку плотности по массе и объёму»

# `reflection` — рефлексия

Последний экран урока: чем класс подводит итог. Поля те же, что у `prompt`,
а место в уроке другое — и просят его отдельно («добавь рефлексию»),
поэтому это отдельный вид, а не вопросы с другим заголовком.

```json
{
  "type": "reflection",
  "items": [
    "Что нового вы узнали о равноускоренном движении?",
    "Какой шаг в решении задачи оказался самым трудным?",
    "О чём вы бы спросили ещё раз?"
  ]
}
```

| поле | обяз. | значения |
|---|---|---|
| `items` | да | вопросы для рефлексии, минимум один |

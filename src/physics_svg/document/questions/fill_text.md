# `fill_text` — пропуски в тексте

Вставить пропущенные слова или величины в предложение.

```json
{
  "type": "task",
  "blocks": [
    { "type": "text", "body": "Вставьте пропущенные слова." },
    {
      "type": "fill_text",
      "template": "При равномерном движении скорость ___v___, а ускорение ___a___.",
      "blanks": { "v": "постоянна", "a": "равно нулю" },
      "bank": ["постоянна", "растёт", "равно нулю"]
    }
  ]
}
```

| поле | обяз. | смысл |
|---|---|---|
| `template` | да | текст с пропусками `___имя___`, хотя бы одним |
| `blanks` | да | имя пропуска → правильное значение |
| `bank` | нет | слова для выбора; без него пропуск заполняется по памяти |

Ключи `blanks` обязаны совпадать с именами в шаблоне. Шаблон без пропусков —
это блок `text`, а не вопрос. `bank` печатается строкой «Слова для выбора:»
над текстом и подчиняется правилам набора (`document.md`): лишние слова —
дистракторы, как «растёт» в примере, а вот слова из `blanks` в банке быть
обязаны, иначе пропуск нечем заполнить.
